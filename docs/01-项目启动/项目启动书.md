# 项目启动书：基于 Vibe Coding 的 C++ 在线评测（OJ）平台

## 1. 项目名称

**基于 Vibe Coding 的 C++ 在线评测（OJ）平台**

## 2. 项目背景与意义

### 2.1 项目背景

在 C++ 程序设计课程与日常算法训练中，学生通常需要经历“阅读题目—编写代码—编译运行—检查结果—修改代码”的反复过程。传统的人工检查方式反馈速度较慢，当学生数量增加时，教师还需要投入较多时间进行代码运行、结果核对和作业统计。

现有大型在线评测平台功能较为完善，但面向小型教学团队或课程实训时，往往存在系统结构复杂、部署成本较高、二次开发门槛较高等问题。因此，本项目计划开发一个轻量级 C++ 在线评测平台，将题目管理、在线代码编辑、自动编译运行、测试用例判定、提交记录、排行榜以及班级作业管理等功能整合到统一系统中。

项目采用 Vibe Coding 辅助开发方式，在需求拆分、代码实现、调试和文档整理过程中提升开发效率，并通过实际工程实践进一步熟悉 C++ Web 服务、数据库、并发判题和 Linux 进程管理等技术。

### 2.2 项目意义

1. **提升编程练习效率**：学生提交 C++ 代码后可快速获得 AC、WA、TLE、MLE、RE、CE 等判题结果，形成即时反馈闭环。
2. **降低教学管理成本**：教师可以统一维护题库、测试用例、班级和作业，并查看学生完成情况，减少人工统计工作。
3. **提高系统工程实践能力**：项目覆盖前后端交互、RESTful API、MySQL 数据库、异步任务队列、Linux 进程隔离、权限控制和自动化测试等内容。
4. **形成可扩展的教学平台**：系统后续可继续扩展比赛模式、数据可视化、代码相似度检测以及 AI 错误反馈等功能。

### 3.1 协作约定

- 使用 Git 进行版本管理，所有成员使用自己的 GitHub/Gitee 账号提交代码。
- 每位成员负责的功能应通过独立 Commit 留下真实开发记录。
- 重要功能开发前进行任务拆分，完成后由其他成员进行代码检查和功能验证。
- `main` 分支保存可运行版本，功能开发建议使用独立分支后再合并。

## 4. 核心功能模块列表（Product Backlog）

> 优先级说明：**P0 = 必须完成的核心功能，P1 = 重要功能，P2 = 增强功能。**

| 编号 | 优先级 | 功能模块 | Backlog 描述 / 验收目标 |
|---|---|---|---|
| BL-01 | P0 | 用户注册与登录 | 支持用户注册、登录、登出；密码采用 bcrypt 哈希保存；通过 Session/Cookie 维护登录状态。 |
| BL-02 | P0 | 题库管理 | 支持题目增、删、改、查；支持难度、标签、关键词搜索和分页；管理员可维护测试用例。 |
| BL-03 | P0 | 题目详情与在线编辑 | 展示题目描述、输入输出要求和代码模板；集成 Ace Editor，支持在线编写 C++ 代码。 |
| BL-04 | P0 | 代码提交与异步判题 | 用户提交代码后立即生成提交记录，由后台判题队列异步执行，前端获取最终判题状态。 |
| BL-05 | P0 | 判题沙箱与资源限制 | 使用 Linux 进程机制执行用户代码；限制 CPU、内存、输出和运行时间，降低恶意代码对服务的影响。 |
| BL-06 | P0 | 多状态判题 | 支持 AC、WA、TLE、MLE、RE、CE 等主要判题结果，并记录错误信息和逐测试用例结果。 |
| BL-07 | P1 | Special Judge | 对非唯一输出题目提供特判机制，通过自定义判题程序判断答案是否正确。 |
| BL-08 | P1 | 提交记录 | 支持查看个人历史提交、代码内容、最终状态以及逐测试用例判题详情。 |
| BL-09 | P1 | 个人统计与排行榜 | 按题目难度统计完成数量；生成全站排行榜，展示用户通过题目数量等信息。 |
| BL-10 | P1 | 班级与作业 | 支持教师创建班级、生成加入码、学生加入班级、教师布置作业并查看成员完成矩阵。 |
| BL-11 | P1 | 管理后台 | 管理员统一管理题目、标签、测试用例和 Special Judge 等数据。 |
| BL-12 | P1 | 提交频率限制 | 对单个用户的代码提交频率进行限制，避免恶意高频提交影响判题服务。 |
| BL-13 | P1 | 自动化测试与部署 | 使用 CMake 构建项目；提供单元测试、接口测试和 Smoke Test；支持 Ubuntu 22.04 / WSL 环境部署。 |
| BL-14 | P2 | 比赛模式 | 创建限时比赛、比赛题目列表和比赛排行榜，引入 AC 数与罚时等比赛统计规则。 |
| BL-15 | P2 | 数据可视化 | 对个人提交趋势、题目难度分布、班级正确率等数据进行图表展示。 |
| BL-16 | P2 | 代码相似度检测 | 对作业提交代码进行相似度分析，辅助教师发现高度相似的代码。 |
| BL-17 | P2 | AI 错误反馈 | 在 CE、WA 等情况下，根据代码和判题信息生成辅助解释，帮助学生定位问题。 |

## 5. 技术方案概述

| 层级 | 技术方案 |
|---|---|
| 前端 | HTML、CSS、JavaScript、Ace Editor |
| 后端 | C++17、cpp-httplib |
| 数据库 | MySQL 8.0 |
| 用户认证 | Session / Cookie、bcrypt |
| 判题执行 | Linux fork/exec、rlimit、异步判题队列 |
| 构建工具 | CMake |
| 测试 | GoogleTest、接口测试、Smoke Test |
| 部署环境 | Ubuntu 22.04 / WSL |

## 6. 项目预期成果

1. 完成一个可以在浏览器中访问和使用的 C++ 在线评测平台。
2. 实现从题目浏览、在线编码、代码提交到自动判题的完整流程。
3. 提供管理员题目维护与教师班级作业管理能力。
4. 建立规范的 Git 协作流程、README、API 文档和测试文档。
5. 为后续比赛模式、教学数据分析和 AI 辅助反馈提供扩展基础。
