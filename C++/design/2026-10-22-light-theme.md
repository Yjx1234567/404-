# CodeOJ 浅色专业学习平台改造

用户于 2026-10-22 选择方案一，授权将现有 9 个页面统一升级。保留原生 HTML/CSS/JavaScript、现有路由、接口、权限和判题流程，不创建原型工程或引入前端框架。

## 已选设计

- 冷灰页面背景、白色内容表面、靛蓝主要操作；正文采用本地中文系统字体，代码使用系统等宽字体。
- 共用顶栏、导航选中状态、标题区、表单、按钮、列表、分页和反馈组件。
- 题库由大卡片改为按编号、题目、难度和创建时间排列的紧凑行式列表。
- 答题页使用浅色题面和深色编辑器，保留 Ace 及 textarea 降级、按题草稿与异步判题；布局变化同步编辑器尺寸。
- 提交记录、排行榜按列对齐；个人中心使用已有统计、难度分布与最近提交；后台整理现有新增和删除功能。
- 首页使用实际代码示例与已有功能介绍；登录、注册统一品牌与表单层级。
- 补充窄屏换行、长文本、键盘焦点、禁用、加载、空数据、错误、判题状态与减少动画偏好。

## 实施顺序

1. 备份现有 public 目录至 design/backups。
2. 重建共享设计变量和样式，分别整理首页与认证页、6 个应用页。
3. 调整动态题库模板、编辑器尺寸与降级样式，保持 DOM ID 和事件契约。
4. 用 Node 执行真实脚本的无浏览器逻辑测试，检查本地 HTML 引用、ID、标签、JS 语法及 CSS 结构。
5. 记录修改范围、验证结果与恢复方式。

## 验证边界

遵守用户要求，不使用电脑控制、浏览器自动化、截图或视觉交互工具。页面视觉由用户自行检查。本次不生成或添加图片资源，不启动数据库、部署或修改后端业务。无浏览器脚本测试只验证相应逻辑与 DOM 契约，不代表真实浏览器、设备或在线服务验证。

当前工作目录没有 Git 仓库，因此不初始化仓库或创建提交。恢复前端时，将 design/backups 内本次 public-before-light-theme 压缩包中的 public 目录解压至项目根目录并覆盖。

## 在原启动方式下使用

**更新：现已提供自动同步的一键入口。日常只需双击 `启动OJ.bat`，无需下面的手动复制步骤。详见 `2026-10-22-one-click-start.md`；以下保留为旧启动方式的排障说明。**

根目录的 `启动OJ.bat` 启动 `~/oj_platform/build/oj_server`，读取 WSL 副本。当前改动保存在 Windows 项目目录，未修改 WSL 副本。

如使用此启动方式，在 Ubuntu-22.04 的终端执行以下命令同步静态文件，之后刷新页面即可，样式改动不需要重新编译 C++：

```bash
cp -a ./public/. ~/oj_platform/public/
```
