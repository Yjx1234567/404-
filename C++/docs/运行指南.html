Ubuntu 22.04 (jammy) 里 libbotan-2-dev 是原生包，装完就能用。
如果你之前已经装了 Ubuntu 24.04：先双击 0-uninstall-old-Ubuntu.bat 删掉它，再从 ① 开始。

为什么需要 WSL？
这个 OJ 项目用了 Linux 专属技术（fork 进程隔离、rlimit 资源限制）来安全地运行学生提交的代码，只能在 Linux 环境编译运行。WSL 是 Windows 官方内置的"Linux 子系统"，装上它就能在 Windows 里运行 Linux 程序，浏览器照常用 Windows 的。

第一步：安装 WSL（只需要做一次）

1以管理员身份打开 PowerShell

  1. 按键盘上的 Win 键（就是田字徽标键）
  2. 输入 powershell
  3. 右键点击搜索结果里的 「Windows PowerShell」，选 「以管理员身份运行」
  4. 弹出蓝色窗口后，粘贴下面这条命令，按回车：
wsl --install -d Ubuntu-22.04
注意一定要带 -22.04。只写 -d Ubuntu 会装成 24.04，那个版本的软件源里没有本项目的密码库，会部署失败。

2等待安装完成后重启电脑

安装过程需要下载约几百 MB，耐心等它跑完。看到提示要求重启时，重启电脑。

如果提示 "wsl --install 失败" 或需要更新内核：先运行 wsl --update 再重试上面的命令。

第二步：首次进入 Ubuntu（设置用户名和密码）

1打开 Ubuntu

重启后，按 Win 键输入 ubuntu，点击打开。会弹出一个黑色或紫色的终端窗口。

2设置用户名和密码（首次打开才会要求）

  • Enter new UNIX username: 输入一个用户名（建议纯小写英文，比如 student），回车
  • New password: 输入密码（屏幕上不会显示任何字符，这是正常的，盲打就行），回车再输一遍
看到 用户名@电脑名:~$ 这样的提示符，就说明成功了。这个密码后面会用到，请记住它。

第三步：一键部署（复制粘贴就行）

1进入项目目录

在 Ubuntu 终端里粘贴这行命令，回车：

cd /mnt/d/projects/cpp-oj-platform

2运行一键部署脚本

chmod +x setup.sh && ./setup.sh

脚本会自动完成下面所有事情（大约 5~15 分钟，取决于网速）：

步骤它在做什么你需要做什么
1/6 安装依赖换清华源，装 g++、cmake、MySQL、Botan2 等输入你刚才设的 Ubuntu 密码（盲打），然后等待
2/6 同步源码把项目复制到 WSL 本地磁盘 ~/oj_platform无
3/6 数据库启动 MySQL、创建用户、建 4 张表可能再输一次密码，等待
4/6 更新配置写入你的用户名无
5/6 编译项目把 C++ 源码编译成程序等待 1~3 分钟
6/6 启动服务创建管理员并启动问 [Y/n] 时直接回车
为什么源码要复制到 ~/oj_platform 再编译？
项目在 Windows 的 D 盘，WSL 通过 /mnt/d 访问它。这个挂载点上 CMake 生成的临时可执行文件没有执行权限，会报 Operation not permitted。所以脚本先把源码同步到 WSL 自己的磁盘（ext4）再编译，这是最稳的做法。
影响：你在 Windows 上改了代码后，需要重新跑一次 2-双击部署OJ.bat 才会同步生效（日常使用不需要改代码）。
看到类似 Server starting on 0.0.0.0:8080 的字样，说明启动成功！这个窗口不要关（关了服务就停了）。

第四步：使用系统

  1. 打开 Windows 里的浏览器（Edge/Chrome 都行），访问：
    http://localhost:8080
  2. 点击登录页，用管理员账号登录：
    用户名密码
    adminadmin123
  3. 进入管理后台可以添加题目；注册一个新用户（如 test/123456）可以做题、提交代码看判题结果

以后如何再次启动（每次开机后）

WSL 重启后 MySQL 和服务都不会自动运行。最省事的做法是双击 3-双击启动OJ服务.bat。

也可以在 Ubuntu 终端里粘贴这两行：

sudo service mysql start cd ~/oj_platform && ./build/oj_server
第一行需要输入 Ubuntu 密码（盲打）。看到 Server starting 后，浏览器访问 http://localhost:8080。不需要重新跑 setup.sh。

常见问题

Q0：在终端里没法复制粘贴怎么办？

三种办法任选：
粘贴：在终端窗口里直接按鼠标右键（即可粘贴剪贴板内容）；或按 Ctrl + Shift + V。
复制：用鼠标选中文字后按 Ctrl + Shift + C，或直接回车复制选中内容（Windows Terminal 默认行为）。
最省事：直接用项目文件夹里的 1-双击安装WSL.bat、2-双击部署OJ.bat、3-双击启动OJ服务.bat，完全不用打字。

Q0.5：我装错成 Ubuntu 24.04 了，怎么办？

正常，很多人第一次都会踩这个坑。做法：
① 双击 0-uninstall-old-Ubuntu.bat，按提示输入大写 YES 删除旧版
② 双击 1-双击安装WSL.bat 装 Ubuntu 22.04
③ 双击 2-双击部署OJ.bat
删除 Linux 子系统不会影响你 Windows 上的任何文件。

Q1：输密码的时候屏幕上什么都不显示？

Linux 的传统就是这样，密码不会显示星号，直接盲打完按回车即可。

Q2：apt 安装特别慢或者失败？

使用双击方案（2-双击部署OJ.bat）的话，脚本会在装包前自动调用 fix_sources.sh 把默认国际源换成清华源，无需手动操作。

如果你是手动跑 ./setup.sh，需要先换源再装包，把下面这条命令完整粘贴到 Ubuntu 终端回车：

bash fix_sources.sh

再重新跑 ./setup.sh。如果清华源也连不上，可以改用阿里源（编辑 fix_sources.sh 把 PRIMARY="mirrors.tuna.tsinghua.edu.cn" 改成 mirrors.aliyun.com）。

Q3：脚本中途报红色 [ERROR] 停了？

把终端里最后 20 行左右截图发给 AI 助手，会告诉你怎么修。常见原因：网络断、密码输错（重新跑一次脚本即可，已完成的步骤会自动跳过或快速重做）。

Q4：浏览器打不开 localhost:8080？

① 确认 Ubuntu 终端窗口还开着且显示 Server starting；
② 试试在 Ubuntu 里另开一个终端窗口跑 curl http://localhost:8080，有 HTML 内容返回说明服务正常，是浏览器问题（换 Edge 试试）；没返回则服务没起来，看终端报错。

Q5：想停止服务？

在运行服务的终端窗口按 Ctrl + C。

Q6：WSL 里能直接访问 D 盘文件吗？

能。/mnt/d/... 就对应 D:\...，项目文件在 Windows 和 WSL 里看到的是同一份。

Q7：编译警告或 gtest 相关测试没跑？

不影响使用。测试是可选项，服务能启动、能做题就说明部署成功了。

Q8：部署时报 E: Unable to locate package libbotan-2-dev？

99% 是因为你用的是 Ubuntu 24.04——那个版本的软件源里已经没有 Botan 2.x 了。请按 Q0.5 换成 Ubuntu 22.04。
如果你确认自己装的是 22.04 还报这个错，那是国际源 archive.ubuntu.com 连不上：
① 编辑 fix_sources.sh，把 PRIMARY="mirrors.tuna.tsinghua.edu.cn" 改成 mirrors.aliyun.com（阿里源）
② 重新跑 2-双击部署OJ.bat

Q9：报 CMake Error ... Operation not permitted？

已解决。脚本现在会把源码同步到 WSL 本地磁盘 ~/oj_platform 再编译，不再在 /mnt/d 上构建。如果你是自己手动跑的老版本脚本，请重新双击 2-双击部署OJ.bat。

Q10：我在 Windows 上改了代码，怎么让改动生效？

重新双击一次 2-双击部署OJ.bat，它会把最新的源码同步到 ~/oj_platform 并重新编译。日常使用（只做题、只加题目）不需要这一步。
